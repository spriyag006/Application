# ✅ Task Manager

## 📌 Project Overview

Task Manager is a web application that helps users organize, track, and manage their daily tasks efficiently. Users can maintain a task list and monitor their progress through a simple and user-friendly interface.

**live website** https://application-3-j20d.onrender.com

## ✨ Features

- ➕ Add new tasks
- 📋 View all tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- ⏳ Track pending tasks
- 📱 Responsive and user-friendly interface

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Visual Studio Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/spriyag006/Application.git
```

**2. Navigate to the project folder**

```bash
cd Application/module4/task_manager
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the application**

```bash
npm start
```

If your project uses Vite instead of Create React App, use `npm run dev` instead.
